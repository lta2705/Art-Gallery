OpenGL to CAD: why the pipeline matters (2/2)
A useful classroom analogy
• OpenGL asks: “How do I draw this object now?”
• CAD asks: “How was this object built, and what
should happen if one dimension changes?”
• In CAD, a hole diameter is not just geometry; it is a
named, editable design decision.
Fully constrained sketch

Key consequence for engineering
• Stable edits are more valuable than one perfect
screenshot.
• A good model survives revision without starting
over.
• That is why we will focus on constraints, pad,
pocket, and feature order.

Troubleshooting for beginners
• Sketch still moves → it is under-constrained; do not
build on it yet.
• Feature appears in the wrong place → the wrong
face or plane was selected before sketching.
• Hole or pocket stops staying centered after edits →
the sketch was constrained to the wrong reference.

If a face is unsuitable, create a datum plane

• A difficult slanted or irregular face may need a datum
plane instead of direct face sketching.

Attach the plane carefully so the next sketch
has a stable reference frame
