Import settings that matter for STL

Import

Use these options intentionally, not by guesswork
Scale — start with 1.0; change only if the imported size is clearly wrong.
Scene Unit — use when scene units already matter to your workflow.
Facet Normals — keeps imported facet normals; useful when you intentionally want flat-looking faces.
Forward / Up Axis — use when the dragon arrives with wrong orientation. Blender expects Y forward and
Z up.
Validate Mesh — helpful for suspicious files, but slower than normal import.

Rule of thumb for class: fix orientation first, then scale, and only then continue to shading or animation.

Before shading: prepare the imported mesh for the rest of the pipeline

Mesh prep

Preparation checklist

Why this matters later

1. Check scale with a known reference or the
grid.
2. Place the dragon near world origin for
predictable camera and path work.
3. Make the dragon face its intended forward
direction before path following.
4. Apply scale only after you are happy with
size.
5. Save a new file version:
lecture9_dragon_scene.blend.

• Wrong scale makes lighting and camera
decisions harder to judge.
• Wrong forward axis produces awkward pathfollow orientation.
• A messy origin or object name makes
debugging much slower.

Step 4 — Frame one successful still render before animating
Recommended classroom order

Why a still render first?

1. Place the camera.
2. Use a 3/4 view so silhouette and depth both
read clearly.
3. Lock one “hero frame” before you think
about motion.
4. Press F12 and evaluate shape, lighting, and
background contrast.

• A bad still render becomes a bad
animation many times over.
• Camera framing problems are easier
to fix on one frame than across 100+
frames.
• This is the fastest checkpoint before
the class invests in render time.

Camera

If frame 1 is not visually convincing, do
not continue to animation yet.

Minimum motion logic

2. Store one transform at the first

4. Let Blender interpolate the values
between them.

Operational rule for today

1) Select the curve

Animate

2) Selec Data -> Path Animation panel

• Keep one simple frame range for the
whole shot (Frames = 100).
• Use Evaluation Time (or path
animation timing) to move from start to
end.
• drag the frame pointer at each point
and set corresponding evaluation time.

Path shape controls WHERE the dragon
goes. Evaluation Time controls WHEN it
reaches each point.

Timeline

Manual timeline view

Step 5 — Set render size, frame rate, and frame range

Render setup

Classroom defaults to stabilize the pipeline

• Use a modest resolution for
previews; scale up only after motion
is correct.
• Pick one frame rate and keep it
fixed across the shot.
• Define Start and End before final
rendering so duration is explicit.
A short, clean animation beats a long,
partially broken one.

Output strategy — render frames first, encode video second

Render output

Recommended classroom workflow

1. Choose an output folder and clear
naming pattern.
2. Render as image sequence first for
safety and restartability.
3. After frames are correct, encode to
a video container.

If rendering stops halfway, image
sequence workflow lets you resume
instead of losing the whole movie file.
