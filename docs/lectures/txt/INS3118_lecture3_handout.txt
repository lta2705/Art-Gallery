Module 1: Geometry & Environment (Student A)
The Room: Construct a 3D room based on the provided floor plan. Walls must be distinct entities.
The Actor: Create a high-fidelity sphere (the "Head").

CCTV Mode: Fixed vec3 position, fixed orientation.
POV Mode: Position and direction updated every frame based on the "Head" coordinates.
Module 3: Illumination & Shading (Student C)
Point Light Logic: The bulb must have a position in World Space.
The Shader: Write a vertex and fragment shader implementing the Phong Reflection Model:
Ambient: Constant base light.
Diffuse: Based on the angle between the surface normal and light direction.
Specular: The "shiny" highlight on the ball that moves with the camera.
Attenuation: Light should naturally get dimmer as the ball moves further away from the bulb.

Normals: why you need a normal matrix (remind)
• Normals must remain perpendicular to the surface after
transforms.
• Non-uniform scale breaks normals if you use mat3(M)
directly.
• Correct: normalMat = transpose(inverse(mat3(M))).
• Always normalize: before and after interpolation.
• We will force a non-uniform scale to validate correctness.

Practice 3: Lambert diffuse + ambient (P3_lambert)
• Goal: implement ambient + Lambert diffuse (no specular
yet).
• Lambert: ndotl = max(dot(N,L), 0).
• Ambient: Ka * ambientColor (simple indirect-light
approximation).
• Checkpoint: faces brighten/darken as light moves around.

Fragment shader (Lambert + ambient)
#version 330 core
in vec3 vWorldPos;
in vec3 vWorldNormal;
out vec4 FragColor;
uniform vec3 uLightPos;
uniform vec3 uLightColor;
uniform vec3 uAmbientColor;
uniform vec3 uKa;
uniform vec3 uKd;
void main(){
vec3 N = normalize(vWorldNormal);
vec3 L = normalize(uLightPos - vWorldPos);
vec3 ambient = uKa * uAmbientColor;
float ndotl = max(dot(N,L), 0.0);
vec3 diffuse = uKd * ndotl * uLightColor;
FragColor = vec4(ambient + diffuse, 1.0);
}

• Phong uses reflection vector R; Blinn-Phong uses halfvector H.
• We keep Lambert diffuse and add specular on top.
• Specular only when ndotl > 0 (light on the front side).
• Toggle with uniform uUseBlinn (set by key B).
