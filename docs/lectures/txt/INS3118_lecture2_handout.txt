Points vs Vectors and Coordinates
• Point: position in space (affected by translation);
• Vector: direction/offset (not translated)
• A coordinate frame is an origin plus a basis (three perpendicular
axes in 3D)
• Homogeneous coordinates add w to unify affine transforms in one
matrix multiply
• w=1 for points, w=0 for directions; translation lives in the last
column of a 4×4
• This distinction is essential for correct motion and lighting
calculations

Inverse Transform: “Undo” a Transformation
• If M is inver ble, M⁻¹ maps back: p = M⁻¹ p'
• Inverses reverse order: (B·A)⁻¹ = A⁻¹·B⁻¹
• Inverse of translation: negate t;
• inverse of rotation: transpose (for pure rotation)
• Used for coordinate transforms: world→local, world→view, etc.

glm::mat4 M = ...;
glm::mat4 Minv = glm::inverse(M);
// Reverse order example
glm::mat4 C = B * A;
glm::mat4 Cinv = glm::inverse(A) * glm::inverse(B);

• Applying the same matrix as positions can break

Common Pitfalls (and How to Avoid Them)
• Degrees vs radians: standardize on radians inside the
program
• Order confusion: write transforms in a consistent TRS
convention
• Mixing spaces: track whether vectors are in local,
world, or view space
• Non-uniform scale affects normals: use correct
normal matrix when lighting
